# Pushup Analyzers Archive

This directory contains archived pushup analyzer implementations that were not working as intended.

## Files Archived:
- `pushup_analyzer_yolo.py` - YOLO-based pushup analyzer
- `pushuptop_analyzer.py` - Alternative pushup analyzer implementation
- `analyzed_pushup_yolo.mp4` - Sample output from YOLO analyzer
- `analyzed_pushup.mp4` - Sample output from standard analyzer

## Reason for Archive:
These pushup analyzers did not work as intended and have been replaced by the working analyzers:
- `hacksquat_analyzer.py` - Working hack squat analyzer
- `row_analyzer.py` - Working row analyzer
- `lat_pulldown_analyzer.py` - Working lat pulldown analyzer

## Date Archived:
January 2025

## Note:
These files are preserved for reference but are not part of the active project.
